# 可选营销方向

这些方向用于启发方案，不能当作商品事实或必须使用的十类受众。

| 方向 | 适用前提 | 文案与画面 |
| --- | --- | --- |
| 居家 | 确实适合家用 | 家庭日常需求，自然晨光与简洁台面 |
| 办公 | 商品能用于办公 | 桌面使用或收纳，避免捏造便携性能 |
| 差旅/户外 | 有对应使用依据 | 真实使用情境，不暗示防摔、防水或耐极端温度 |
| 送礼 | 商品可作为礼物 | 礼物用途；非随货礼盒不能表现成包装组成 |
| 学习 | 商品适合学习场景 | 书桌需求，不写无依据的“最低价” |
| 家庭共用 | 适用对象有依据 | 温润空间，不凭场景宣称低敏、母婴适用 |
| 设计与质感 | 外观材质可观察 | 细节与材质，不写虚构的专柜或五星级标准 |
| 日常使用 | 普通高频用途 | 清晰展示操作，不编“热销第一” |
| 专业应用 | 有性能规格支持 | 真实工作情境，专业性能需证据 |
| 套装/囤货 | 实际销售数量符合 | 展示真实套装；单件商品改用另一购买动机 |

每套记录受众需求、关键词、文案结构、图片差异和事实来源。若商品只支持少数使用场景，可在同一场景内探索不同购买动机，不得强行制造十种功能。
