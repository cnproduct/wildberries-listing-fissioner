# 失败原因追问与制作规则修复（2026-10-11）

## 本次失败的证据

货号 1879785812，任务 om_x100b63f4aa3d14a0b296c89eebe9ba6：前 2 张通过，第 3 张经过 3 次制作仍未通过商品与拍摄要求核对。审查记录分别指出机位没有改变到要求的右侧三分之四角度、标签文字失真、画面出现额外商品、缺少应展示的包装盒。任务停在生成图片质量检查，不是 WB 上架 API 写入失败。

旧执行器只保留 GatewayError 类型，用户追问又落入商品链接提示，所以看不到已存在的详细原因。

## 修改

- 将私有审查记录转换为限定的原因代码与计数；不把原始日志、令牌、账号或路径发送给用户。
- 支持“什么原因处理失败”“为什么失败”“怎么回事”“失败了怎么办”，按用户和聊天定位任务。询问原因不会创建、重试或发送成品。
- “进度”也显示具体失败阶段和处理建议。旧记录无证据时明确说明未知，不推断 WB API 故障。
- 只允许鉴权维护接口为已失败任务补充限定诊断字段，不改任务状态、归属，不触发发送。
- 加强图片提示中对额外商品、镜像倒影和应展示原包装盒的检查。保留真实商品质量门槛。
